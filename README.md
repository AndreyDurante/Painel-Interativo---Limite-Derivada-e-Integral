# O Preço do Progresso

Dashboard interativo que explora a relação entre trabalho, tecnologia, custo de vida e tempo livre.

## Objetivo

O projeto mostra como o avanço digital pode aumentar a produtividade e o acesso à informação, mas também gerar pressões como jornadas longas, custo de conectividade e redução do tempo para descanso.

## Tema

A ideia central é analisar o paradoxo entre:

- tempo de trabalho
- poder de compra
- custo da conectividade
- bem-estar e burnout
- qualidade de vida em diferentes cidades

## Funcionalidades

- Simulador de salário, jornada, deslocamento e custo de internet
- Comparação entre cenários de equilíbrio, precarização e burnout
- Mapa visual de desequilíbrio entre cidades
- Indicadores dinâmicos sobre renda, tempo livre e esgotamento
- Gráfico comparativo dos principais indicadores

## Observação

Este projeto foi desenvolvido como uma interface de análise e tomada de decisão, com foco em apresentar visualmente o impacto das variáveis no cotidiano das pessoas.
